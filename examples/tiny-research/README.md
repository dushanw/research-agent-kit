# Tiny research fixture

Purpose: demonstrate a bounded research task, not replicate a scientific paper.

Contract: for nonempty finite, nonconstant data, output (x - min) / (max - min).
Reject empty, constant and nonfinite inputs. Thus [2, 4, 6] -> [0, 0.5, 1].
The input/output expectations are analytically specified, not generated by the implementation.

The starting code is intentionally broken. `researchflow demo` first records the
failing baseline, applies a known fixture repair, and reruns the checks.
`demo.py` produces `outputs/result.json`. No private data or downloads are used.
