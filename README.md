# ResearchFlow 3.0.0

**Start with [START_HERE.md](START_HERE.md).**

Talk to Claude Code. Use approved Cursor models for independent method checks and fresh diagnoses. Run recorded tests. Use Codex for a separate review. Keep one readable project status and retain human control of integration.

This simplified successor installs beside earlier kits; it does not overwrite v1/v2 files or migrate old approval records. A previous agent's research project can be taken over through the same source-preserving process as any other project.

Main user commands: `setup`, `doctor`, `start`, `status`.

The commands Claude uses: `task`, `baseline`, `consult`, `check`.

Maintenance: `selftest`, `demo`, `feedback`, `develop`, `update`, `rollback`.
